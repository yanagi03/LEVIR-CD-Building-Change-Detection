
# Building Change Detection — LEVIR-CD

## Описание проекта

Проект посвящён автоматическому обнаружению изменений
застройки на спутниковых снимках высокого разрешения
с использованием нейронной сети Siamese U-Net.

Модель получает два спутниковых снимка одной территории,
сделанных в разные даты, и формирует бинарную маску
изменений зданий.

## Используемые данные

### LEVIR-CD
Основной датасет для обучения и тестирования.

Источник:
https://justchenhao.github.io/LEVIR/

Подготовленная выборка:
- Train: 3144 пары
- Validation: 433 пары
- Test: 931 пара
- Размер изображений: 256×256

### S2Looking
Независимый датасет для проверки
обобщающей способности модели.

Источник:
https://github.com/S2Looking/Dataset

## Метод

Используется сиамская нейронная сеть с общими весами
энкодера и декодером сегментации.

Проведены эксперименты с:
- BCE и BCE + Dice Loss;
- геометрическими аугментациями;
- упрощённой и полноценной Siamese U-Net;
- конкатенацией и абсолютной разностью признаков.

## Запуск

1. Установить зависимости.
2. Скачать LEVIR-CD по ссылке выше.
3. Подготовить данные.
4. Выполнить обучение.
5. Выбрать лучшую модель на Validation.
6. Оценить модель на Test.
7. Скачать S2Looking и провести внешнюю проверку.
